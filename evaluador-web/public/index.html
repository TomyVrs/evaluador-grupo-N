Paso 1

Cargar trabajos

Podés mezclar fuentes en el mismo lote. Los archivos locales se procesan en el navegador y no se suben a ningún servidor.

GH

Repositorios GitHub

Una URL por línea. Acepta repos completos o carpetas /tree/ref/ruta.

DIR

Carpeta local

Elegí una entrega o una carpeta que contenga varias entregas en subcarpetas.

Se conserva una huella local para identificar la corrida. Los archivos no salen del navegador.
ZIP

Archivos ZIP

Podés seleccionar uno o varios ZIP. Cada ZIP puede contener una entrega o varias carpetas de trabajos.

ZIP soportado en navegadores modernos para archivos estándar sin contraseña.
