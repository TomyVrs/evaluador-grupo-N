# Análisis económico

## Costo por corrida

El caso declara un costo estimado de **USD 0,03 por corrida**. Es una estimación documentada dentro de las notas de entrada, no una factura ni un dato de consumo medido.

## Proyección

Con la frecuencia declarada de **3 corridas semanales** y **52 semanas anuales**:

- Corridas anuales: 3 × 52 = **156**.
- Costo anual estimado: 156 × USD 0,03 = **USD 4,68**.

## Elección del modelo

Para esta tarea acotada se propone el modelo más pequeño que mantenga extracción fiel, salida JSON válida y detección de contradicciones. La elección debe confirmarse con pruebas comparativas; este caso no presenta una medición independiente de calidad ni precios de proveedor.

## Límites de la evidencia

No se debe transformar la estimación en un costo real ni inferir tokens no registrados. Las corridas incluidas declaran que el conteo de tokens no estuvo disponible.
