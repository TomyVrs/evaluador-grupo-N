# Decisiones del caso flojo

Se intentó construir un asistente general para resumir textos.

- No se documentaron iteraciones completas.
- No se conservaron los errores textuales de las pruebas.
- No se identificó una herramienta o conector real.
- Se realizó una prueba manual, pero faltan la entrada original, la fecha y dos corridas adicionales.
- No se definieron permisos, nivel de supervisión, contingencias ni firmante.

Este caso queda deliberadamente incompleto. No debe recibir puntos por afirmaciones que no tengan evidencia verificable.
